# Своё Вино — ИИ-сомелье и конструктор дегустаций

Один файл `index.html`, без сборки и сервера. Откройте в браузере или опубликуйте на GitHub Pages.

- `#chat` — сомелье: подбор к блюду, в подарок, по вкусу, бюджету, сорту, региону и событию
- `#saved` — мои вина и вкусовой профиль
- `#events` — дегустации: создание, программа, QR, итоги, передача в Народный винный рейтинг
- `#join-КОД` — анкета участника
- `#tests` — автотесты точности и защиты от выдуманных позиций

## GitHub Pages
1. Новый публичный репозиторий, загрузите `index.html` и `.nojekyll` в корень.
2. Settings → Pages → Deploy from a branch → `main` / `(root)`.
3. Адрес: `https://<логин>.github.io/<репозиторий>/`.
